# Task Manager

A simple task manager web app built with plain HTML, CSS and JavaScript. Add tasks with a title and a category (Work, Personal, Study or Other), update or delete them, and everything is saved in the browser's localStorage — so your tasks are still there when you come back.

## Features

- Add, update and delete tasks
- Categories: Work, Personal, Study, Other
- Tasks persist in localStorage — no backend needed
- Mobile responsive layout

## Tech

HTML · CSS · JavaScript (localStorage)

## Run it

Open `index.html` in any browser, or use a static server:

```bash
npx serve .
```
